# 3D Models Directory

This directory should contain the 3D mannequin models:

- `male-mannequin.glb` - Male mannequin model
- `female-mannequin.glb` - Female mannequin model

## Model Requirements:

1. **Format**: GLB (GLTF Binary) format
2. **Texture Support**: Models should have proper UV mapping for texture application
3. **Body Parts**: Models should have properly named meshes for outfit application:
   - Body/Torso
   - Arms
   - Legs
   - Full (for full body outfits)

## Recommended Sources:

1. **Mixamo** - Free 3D characters with proper rigging
2. **Sketchfab** - Various mannequin models (check licenses)
3. **ReadyPlayerMe** - Customizable avatar system
4. **MakeHuman** - Open source human model generator

## Setup Instructions:

1. Download or create your mannequin models
2. Ensure they have proper UV mapping
3. Export as GLB format
4. Place in this directory with the correct filenames
5. Test with the OutfitPreview component

## Note:
The models used in the animation page (`/models/er.glb`) can be reused here if they have proper UV mapping for texture application.
